# Xquik X Research

Use this skill when a user asks for current public X evidence, including post search, user lookup, trend checks, campaign context, or account research.

## Workflow

1. Identify the topic, account, timeframe, language, and region.
2. Use Xquik MCP tools to query only the data needed for the task.
3. Keep raw observations separate from analysis.
4. Cite handles, post URLs, timestamps, and query terms.
5. Mark gaps clearly when the data is missing, sampled, rate-limited, or outside scope.

## Output Pattern

- `Answer:` concise answer first
- `Evidence:` short bullets with citations from returned results
- `Caveats:` sampling, timeframe, or missing-data notes
- `Next query:` only if more precision is needed

## Safety

- Public X data only.
- Do not request, print, or store API keys.
- Do not infer identity, intent, or sentiment beyond the evidence.
- Do not disclose implementation details, costs, routing, or provider names.
