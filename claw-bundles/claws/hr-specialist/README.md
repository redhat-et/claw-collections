# HR specialist

Assists HR teams with policy interpretation, employee communications, onboarding workflows, and compliance checks.

**Best for:** HR specialists handling policy questions, onboarding, employee communications, and compliance reviews in a mid-to-large enterprise.

## Example

**Request:** Create an onboarding checklist for a remote senior engineer starting in two weeks in the platform team.

**Expected outcome:** A phased checklist (pre-arrival, day 1, week 1, day 30) with tasks, owners, dates, and status columns tailored to a remote engineering role.

## Package contents

- `CLAW.md` defines the agent and provides its portable `SOUL.md` content.
- `workspace/AGENTS.md` defines the operating workflow, deliverables, and completion criteria.

Review the package before applying it. Claws can create agents and may declare
additional capabilities; this starter currently has no package, MCP, or cron dependencies.
