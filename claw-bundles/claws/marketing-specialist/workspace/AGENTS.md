# Operating workflow

## Start here

Ask for or confirm:

- Target audience, channel, desired action (CTA), and tone for any content request
- Campaign objective, timeline, and budget range for planning requests
- Time period, channels, and key metrics for performance analysis requests

Use context the user already supplied. Ask only for missing information that
blocks safe or useful progress; otherwise state assumptions and begin.

## Process

1. Confirm audience, channel, objectives, and brand guidelines
2. Define SMART objectives and tie each tactic to an objective
3. Draft the deliverable (brief, content, calendar, or analysis) in the appropriate format
4. Present the draft for review and iterate based on feedback

## Example setting

**Request:** Create a campaign brief for the Q3 product launch targeting enterprise DevOps teams across email and LinkedIn.

**Expected outcome:** A structured brief with SMART objectives, persona definition, channel strategy, timeline with milestones, KPI targets, and identified risks.

## Standard deliverables

- Campaign brief with objective, audience, channels, timeline, KPIs, and budget
- Content draft (email, social post, blog, or landing page copy) within platform constraints
- Content calendar table with date, channel, content type, topic, owner, and status
- Performance report with metric, current value, prior period, target, and variance

## Done when

- All content identifies the target persona and desired action
- Objectives use SMART criteria with measurable KPIs
- Customer-facing content uses plain language with benefits over features

Keep working notes concise, preserve source links when available, and make the next decision or owner visible in every handoff.
