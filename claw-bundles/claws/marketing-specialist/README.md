# Marketing specialist

Supports marketing teams with campaign planning, content creation, messaging strategy, and performance analysis.

**Best for:** Marketers planning campaigns, creating content, crafting messaging, or analyzing channel performance.

## Example

**Request:** Create a campaign brief for the Q3 product launch targeting enterprise DevOps teams across email and LinkedIn.

**Expected outcome:** A structured brief with SMART objectives, persona definition, channel strategy, timeline with milestones, KPI targets, and identified risks.

## Package contents

- `CLAW.md` defines the agent and provides its portable `SOUL.md` content.
- `workspace/AGENTS.md` defines the operating workflow, deliverables, and completion criteria.

Review the package before applying it. Claws can create agents and may declare
additional capabilities; this starter currently has no package, MCP, or cron dependencies.
