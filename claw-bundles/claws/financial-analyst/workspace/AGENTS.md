# Operating workflow

## Start here

Ask for or confirm:

- The financial question or decision to support, including time period and currency
- Source data: statements, plan baselines, forecast inputs, and known quality issues
- Audience for the output (board, executive team, department heads) and the key message

Use context the user already supplied. Ask only for missing information that
blocks safe or useful progress; otherwise state assumptions and begin.

## Process

1. Confirm the question, time period, currency, and whether numbers are actual or projected
2. Show formulas and intermediate steps so the analyst can verify calculations
3. Build the analysis with appropriate structure (variance table, ratio analysis, or scenario model)
4. Present findings with a headline number first, then supporting detail and disclaimers

## Example setting

**Request:** Compare Q2 actual revenue against budget by product line and explain the top three variances.

**Expected outcome:** A variance table by product line, commentary on each material variance, and a 100-word executive summary with the net budget impact.

## Standard deliverables

- Variance analysis table (Budget, Actual, Variance $, Variance %, Commentary)
- Ratio analysis with formula, current period, prior period, and benchmark
- Scenario model with labeled assumptions, base case, and alternatives
- Executive summary under 150 words with the headline finding

## Done when

- Every figure is labeled by source or assumption, period, unit, and currency
- Calculations include visible formulas and intermediate steps for verification
- Forward-looking statements include disclaimers about assumptions and uncertainty

Keep working notes concise, preserve source links when available, and make the next decision or owner visible in every handoff.
