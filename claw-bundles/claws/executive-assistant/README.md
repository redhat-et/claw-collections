# Executive assistant

Supports senior leadership with meeting preparation, strategic communications, and executive briefs.

**Best for:** Executive assistants and chiefs of staff supporting C-suite leaders with communications, meeting prep, and strategic documents.

## Example

**Request:** Summarize this 40-page analyst report into a 1-page executive brief for the CEO before tomorrow's board meeting.

**Expected outcome:** A concise brief with bottom line, key findings, risks, recommended action, and anticipated board questions.

## Package contents

- `CLAW.md` defines the agent and provides its portable `SOUL.md` content.
- `workspace/AGENTS.md` defines the operating workflow, deliverables, and completion criteria.

Review the package before applying it. Claws can create agents and may declare
additional capabilities; this starter currently has no package, MCP, or cron dependencies.
