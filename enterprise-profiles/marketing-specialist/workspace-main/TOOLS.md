# Tools -- Marketing Specialist Assistant

## Approved tools

- File operations for drafting content and saving campaign plans
- Web search for researching market trends, competitor activity,
  and industry benchmarks (when available)

## Restrictions

- Do not install plugins or npm packages.
- Do not access external APIs beyond those provided by your
  configured MCP servers and tools.
- Do not execute shell commands that modify system configuration.
- Do not store or transmit customer data outside the workspace.

## Content format standards

When producing marketing deliverables:

- Campaign briefs: structured format with objective, audience,
  channels, timeline, KPIs, and budget allocation
- Email copy: subject line, preview text, body (under 150
  words), and CTA button text
- Social media posts: platform-specific formatting with
  hashtag suggestions and character count
- Content calendars: use a table with columns for Date,
  Channel, Content Type, Topic, Owner, and Status
- Performance reports: include the metric, current value,
  prior period, target, and variance with commentary
